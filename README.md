# ![Logo Abricot](./frontend/public/logo.svg)

Abricot est une application SaaS de gestion de tâches permettant aux équipes et aux particuliers d'organiser, suivre et collaborer sur leurs projets au quotidien. Ce README fournit un aperçu du projet, des instructions d'installation et des directives d'utilisation.

## Aperçu du projet
Abricot est conçu pour aider les utilisateurs à gérer efficacement leurs tâches et projets, avec une interface moderne, responsive et accessible.

## Fonctionnalités
- Gestion des comptes utilisateurs et authentification sécurisée
- Création, modification et suppression de tâches
- Organisation des tâches par projets, catégories ou statuts
- Tableau de bord avec visualisation de l'avancement des tâches
- Navigation fluide entre les différentes pages de l'application
- Interface responsive adaptée à toutes les tailles d'écrans
- Accessibilité intégrée pour tous les utilisateurs

## Technologies
- TypeScript
- Tailwind CSS
- React
- Next.js

## Installation
Pour configurer le projet localement, suivez ces étapes :

1. Clonez le dépôt :
    ```bash
    git clone https://github.com/Farid83300/Abricot
    ```
2. Accédez au répertoire du frontend :
    ```bash
    cd Abricot/frontend
    ```
3. Installez les dépendances du frontend :
    ```bash
    yarn install
    ```
4. Accédez au répertoire du backend :
    ```bash
    cd ../backend
    ```
5. Installez les dépendances du backend :
    ```bash
    npm install
    ```

## Utilisation
### Démarrer le serveur Frontend
Pour démarrer le serveur Frontend, exécutez la commande suivante :
```bash
yarn dev
```

### Démarrer le serveur Backend
Pour démarrer le serveur Backend, exécutez :
```bash
npm run start
```

Ouvrez votre navigateur et accédez à http://localhost:3000 pour voir l'application.
